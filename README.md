# NSS SLIET Longowal

### National Service Scheme — Sant Longowal Institute of Engineering & Technology

🌐 **Website:** https://nsssliet.in/  
🏫 **Institute:** Sant Longowal Institute of Engineering & Technology (SLIET), Longowal, Punjab

---

## About

**NSS SLIET Longowal** is a web platform for the National Service Scheme activities of SLIET.

The website provides information about NSS activities, events, volunteers, team members, photographs, announcements, and youth opportunities.

> **NSS Motto: "Not Me But You"**

Official SLIET NSS information:  
https://sliet.ac.in/nss/

---    

## Features

- 🏠 NSS Home & Introduction

## Local Setup

Clone the repository:

```bash
git clone <repository-url>

```

For a simple local server:

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Content & Privacy

All NSS, SLIET, event, team, and volunteer information should be **verified before publication**.

Do not publish sensitive personal information such as:

- Government IDs
- Passwords
- Private credentials
- Unapproved phone numbers
- Private documents

Photographs and personal information should be published only with appropriate authorization.
