# NSS SLIET Photo Library

Put event photography in this folder so the gallery stays separate from page markup.

Suggested structure:

```text
assets/photos/
├── 2026/
│   ├── environment/
│   ├── education/
│   ├── health/
│   └── outreach/
├── 2027/
│   ├── environment/
│   ├── education/
│   ├── health/
│   └── outreach/
└── featured/
```

Use descriptive filenames such as `2026-environment-rally-01.jpg`.

Only upload photos NSS/SLIET is permitted to publish. Captions, dates and event metadata should be maintained separately in `data/photos.js`.
